# Sentempo — Luxury Property Listings

> A showcase project built as part of my freelance portfolio.

A sleek, ultra-premium property listing website built with **HTML, CSS, and TypeScript**. Designed to demonstrate my frontend skills — live filtering, map integration, and a polished luxury UI.

🔗 **Live Demo:** [property-listing-site.vercel.app](https://property-listing-site.vercel.app/)

---

## About This Project

This is a personal portfolio project I built to showcase my ability to create high-end, production-ready web interfaces. The design targets the luxury real estate market with a focus on clean aesthetics, smooth interactions, and intuitive UX.

**What it demonstrates:**
- Building responsive, visually polished UIs from scratch
- Client-side search and multi-filter logic in TypeScript
- Map integration for location-aware listings
- Deploying static sites with Vercel

---

## Features

- 🔍 **Live Search** — Instant keyword filtering as you type
- 🏷️ **Smart Filters** — Filter by property type, price range, and bedrooms
- 🗺️ **Interactive Map** — Sentempo Atlas view to locate each property
- 📱 **Fully Responsive** — Works beautifully on desktop and mobile
- ⚡ **Zero Page Reloads** — All filtering is client-side and instant
