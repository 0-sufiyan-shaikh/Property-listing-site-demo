## 📖 Overview

**Sentempo** is an ultra-premium luxury real estate listing template built with vanilla HTML, CSS, and TypeScript. It presents forty curated residences across the Americas with live search, multi-filter controls, and an integrated map view — all in a minimal, editorial design language built for high-end clientele.

> *"Forty exceptional properties across the Americas. Filter, explore, and locate each residence in real time."*

---

## ✨ Features

- **🔍 Live Search** — Instant keyword filtering across all 40 listings as you type
- **🏷️ Type Filter** — Filter by property type (Villa, Penthouse, Estate, etc.)
- **💰 Price Filter** — Range buckets: Under $3M · $3M–$5M · $5M–$8M · $8M+
- **🛏️ Bedroom Filter** — Filter from 1+ up to 5+ bedrooms
- **🗺️ Integrated Map View** — Locate every residence geographically in real time
- **🔄 Reset Controls** — One-click filter reset back to full collection
- **📱 Fully Responsive** — Scales beautifully from mobile to ultrawide desktop
- **⚡ Zero Dependencies** — Pure HTML, CSS & TypeScript — no frameworks, no bloat
- **🎨 Editorial Design** — Ultra-minimal luxury aesthetic with refined typography

## 🚀 Getting Started

### Prerequisites

- A modern browser (Chrome, Firefox, Safari, Edge)
- Node.js `18+` (for TypeScript compilation, optional)

### Run Locally

```bash
# Clone the repository
git clone https://github.com/your-username/sentempo.git

# Navigate to the project directory
cd sentempo

# Open directly in browser (no build step needed for HTML/CSS)
open index.html
```

### With TypeScript Compilation

```bash
# Install TypeScript globally if needed
npm install -g typescript

# Compile TypeScript
tsc

# Open the site
open index.html
```

## 🎨 Design Philosophy

Sentempo follows an **editorial luxury aesthetic** — the same visual language used by Sotheby's, Christie's, and Architectural Digest. Key design principles:

- Generous whitespace and refined negative space
- Restrained color palette (near-black, white, warm neutrals)
- High-contrast serif/sans-serif type pairing
- Photography-first card layouts
- No decorative clutter — every element earns its place
